# 🍽️ NutriPlan - Application de Planning Alimentaire Intelligent

Application PWA moderne et élégante pour créer des plannings alimentaires personnalisés basés sur vos objectifs nutritionnels.

## ✨ Fonctionnalités

### 🎯 Phase 1 : Calcul des Besoins
- **Questionnaire intelligent** : Recueille vos données anthropométriques, habitudes de vie et objectifs
- **Calculs scientifiques précis** basés sur les formules de Mifflin-St Jeor et Katch-McArdle
- **Ajustement selon l'objectif** : maintien, perte de poids, prise de muscle, recomposition, rééquilibrage

### 📊 Phase 2 : Génération du Planning
- **Plans personnalisés** : 1, 7 ou 31 jours
- **Base de données** : 10+ petits déjeuners, 100+ déjeuners/dîners, collations variées
- **Ajustement intelligent** : quantités adaptées avec marge ±5%
- **Informations complètes** : calories, macros, micronutriments

## 🚀 Technologies

- **React 18** + TypeScript
- **Vite** pour un build ultra-rapide
- **Tailwind CSS** pour le design
- **Framer Motion** pour les animations
- **Zustand** pour la gestion d'état
- **PWA** avec Service Workers
